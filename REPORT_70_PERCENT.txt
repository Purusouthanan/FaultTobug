1. EXECUTIVE SUMMARY & PROBLEM STATEMENT
------------------------------------------------------------------------
Production bug reports in access-controlled systems are logged in natural
language. Engineers manually triage tickets (~45 mins), apply hotfixes,
and close tickets without writing automated regression tests. Resolved
RBAC defects frequently regress in subsequent releases.

This platform bridges this gap by automatically converting natural
language incidents into permanent, executable Pytest regression tests.
At the 70% milestone, the platform delivers automated NLP parsing,
multi-role RBAC boundary checking (Doctor vs Nurse vs Billing Clerk),
deterministic Pytest generation, AST security sandboxing (with 15s
timeouts), and quantitative ROI telemetry.

3. ARCHITECTURE & PIPELINE WORKFLOW
------------------------------------------------------------------------
Modular Monolith: Presentation (React 19) <-> Application (FastAPI) <-> Sandbox

1. NLP Analysis (analysis_engine.py): Extracts actor, action, resource via
   analysis_rules.yaml; resolves expected vs actual behavior via rbac.yaml;
   categorizes failure (Authorization, Authentication, Validation, etc.).
2. Reproduction (reproduction_engine.py): Produces structured JSON steps:
   Login -> HTTP Request -> Status Assertion.
3. Test Generation (test_generator.py): Synthesizes Pytest code using
   TestClient fixtures, dynamic URL path replacement, and role tokens.
4. Sandboxed Execution (execution_engine.py): Spawns Pytest in .sandbox/
   with AST static safety checks, 15s execution timeout, and stripped env.
5. Regression Repository (routers/regression.py): Promotes passing tests
   to regression_tests table and executes multi-test batches on demand.
